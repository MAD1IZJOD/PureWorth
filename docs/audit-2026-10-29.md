## Confirmed failures and fixes

| Finding | Observed behavior | Stabilization |
| --- | --- | --- |
| Leading decimal | `.5 L` could become 5 L | Parse the decimal as 500 ml using exact normalization |
| Ignored qualifiers | Known-brand requests could discard “lactose free”, an unrelated variant, or extra quantity text | Reject ambiguous/unrecognized details explicitly; preserve the existing cart |
| Brand prefix | “Amulya” was recognized as “Amul” | Match complete brand names at word boundaries |
| Quantity editor | Clearing the number immediately restored it, blocking normal keyboard replacement | Allow a draft; commit a valid size on blur/Enter; restore the previous size and explain invalid edits |
| Hidden inferred detail | Default variant was absent from the list row | Display the interpreted variant with the size and brand |
| Skip link | Scrolled without transferring keyboard focus | Make the shopping-list destination programmatically focusable |
| Off-screen feedback | Hero input errors could appear below the mobile viewport | Focus and scroll to the visible error banner; explain empty store selections |
| Gateway error | HTML error pages exposed raw JSON-parser text | Show a readable retry message and keep the shopping list |
| Bounded-result wording | A secondary strategy still referred to “lowest total”; a missing strategy could imply proven infeasibility | Use “best total found” and explicitly identify unproven feasibility |
| Long error detail | Unbroken validation text overflowed desktop/tablet | Constrain the flex item and wrap long words |
| Checkout copy | Singular baskets used “1 simulated store orders” | Correct singular/plural wording |

The initial audit regressions recorded seven parser failures before repair. The first broad browser run subsequently recorded 223 passes and two long-message overflow failures. After the wrapping fix, both targeted regressions passed and the entire suite was rerun. A navigation test was also corrected to avoid trying to mouse-click the off-screen skip link after already exercising it by keyboard; its focus assertion remains enforced. No failing case was removed or skipped.

## Optimizer proof status and savings

The underlying algorithm required no changes. Complete enumeration still produces `optimal` only within the eligible catalog and restrictions. The actual 12-line capped scenario returns `bounded` at exactly 200,000 nodes, with a visible explanation and best-found labels. Low-budget unit cases separately verify that failing to find a basket before the cap does not become a false infeasibility claim.

Every savings reference must be a complete eligible single-store basket. Unit fixtures also force a feasible split basket with no single-store solution and assert null reference/savings. Bounded references are labelled “Best found”, rather than “Cheapest”.

The normal example still compares ₹1,039 with the valid ₹1,055 Freshlane reference: ₹16 lower. Delivery-budget options of ₹0/₹10 choose the two-store result, whereas ₹20/₹50 allow the single-store option. All four controls were exercised against the real API.

## Control and state coverage

Navigation and footer anchors were clicked and their destinations checked; the keyboard-only skip link was exercised through Tab/Enter. Retailer disclosures expand/collapse. List controls cover add, remove, edit size/brand, valid/invalid replacements, count limits 1–20, example loading and recovery to/from an empty list.

All store selectors, service areas, store-count limits and delivery-budget options are exercised. Alternative approval and revocation are tested, as is invalidation after preference edits. Delayed-request fixtures verify loading feedback and disabled mutation controls. Gateway-error fixtures verify preservation and retry. All strategy buttons, downloads and checkout close/Escape/back controls are covered, including focus restoration. Payment/ordering controls remain explicitly unavailable.

The final suite checks horizontal overflow on representative list, matching and result states and long-input error states. No overflow remained at tested sizes. Some nonessential navigation links are intentionally hidden at mobile breakpoints; their information remains reachable through the page and the “See how it works” link.
